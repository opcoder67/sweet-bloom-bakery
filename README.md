# Sweet Bloom Bakery

A polished, responsive cake and bakery website built with HTML, CSS, and JavaScript.

## View locally

Open `index.html` in your browser, or start a small server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Responsive desktop and mobile layouts
- Product category filters
- Interactive shopping cart counter
- Mobile navigation
- Custom occasion section
- Contact call-to-action
